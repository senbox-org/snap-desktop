Class Fraction / Probability Renderer

The Class Fraction / Probability Renderer displays an arbitrary number of co-registered class bands as one colour composite. It is intended for exploratory display of class fractions, probabilities, memberships, abundances, and comparable numeric class layers. It does not create a product band or modify source samples.

Open it by selecting a product in Product Explorer and choosing Window > Open Class Fraction / Probability View, or by using the product context menu.

Creating suitable input products

The renderer does not run a classification or unmixing algorithm itself. It accepts any numeric class bands from one product that share a raster grid. The following SNAP operators are common producers of suitable band groups:

  • EM Cluster Analysis (Raster > Classification > Unsupervised Classification > EM Cluster Analysis) creates posterior cluster-probability bands when Include probabilities is selected. Use the complete probability_0 ... probability_N group. class_indices is a winning-class map, not a probability-band group.
  • OWT Classification (Optical > Thematic Water Processing > OWT Classification) creates optical water-type membership bands. Use norm_class_1 ... norm_class_N for the normalized membership group. Raw class_* memberships can also be displayed, but normally require a larger display scale. For OWT memberships, select Ignore source masks; accept finite values (OWT zeros) so a finite zero membership remains valid.
  • Spectral Unmixing (Optical > Spectral Unmixing) creates one abundance band per endmember. For a fraction group, select a fully constrained LSU model and use the resulting <endmember>_abundance bands, not optional error bands.

Other operators or imported products are equally suitable when their selected bands describe related classes, are co-registered, and have compatible numeric validity information.

Class-band table

Each row configures one original product band:

  • Band identifies the source band. The renderer accepts only bands from the selected product on the same raster grid.
  • Class name is the label used by the renderer and statistics.
  • Color assigns the colour contributed by that class.
  • Show in View controls whether the class contributes its colour. It does not exclude the band from validity checks or statistics.

Use Add band and Remove selected to configure the group. At least two bands are required.

Display scale and validity

For every valid pixel, the renderer adds each visible class value multiplied by its assigned red, green, and blue colour components. The final RGB channels are divided by Display scale, rounded, and limited to the display range. A scale of 1.0 is the baseline. Increasing it makes the display darker but never changes source values or statistics.

  • Use source validity masks (default) requires every configured class value to be finite, not declared NoData, and valid according to its source valid-pixel mask.
  • Ignore source masks; accept finite values (OWT zeros) requires finite, non-NoData values but deliberately ignores source valid-pixel masks. Use this for OWT normalized memberships whose valid-pixel expression excludes meaningful zero memberships.

If any configured source is invalid under the selected policy, the rendered pixel is transparent. The renderer does not infer science semantics, normalize classes per pixel, resample inputs, or reverse the colour composite into class values.

Actions

  • Open View creates a display-only Class Fraction / Probability view.
  • Show Statistics computes statistics from the original configured bands without opening an image view.

For common-validity statistics, ROI masks, histograms, percentiles, and CSV export, see Class Fraction / Probability Statistics and ROI Analysis.
