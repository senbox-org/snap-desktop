Class Fraction / Probability Statistics and ROI Analysis

Class Fraction / Probability Statistics

Open this dialog with Show Statistics in the Class Fraction / Probability Renderer dialog. Statistics use the original configured source bands, never the rendered RGB image. Display scale is a display-only setting and has no effect on the results.

Common validity

A selected pixel contributes to every class row only when every configured source band is valid according to the validity policy chosen in the renderer dialog. The status line reports selected, common-valid, and excluded pixels. This makes rows directly comparable. The Show in View setting does not affect statistics.

ROI masks

Select Whole scene or a compatible product mask from the ROI list. A compatible mask belongs to the same product and has the same raster grid as the configured class bands. Geometry masks, Band Maths masks, existing quality masks, and compatible vector or image masks can be used.

Refresh statistics is enabled only when the selected ROI differs from the ROI represented by the displayed result. It recomputes the original-band statistics for that ROI.

Table and histogram

The table provides valid-pixel count, minimum, maximum, mean, standard deviation, and estimated P05, P25, median, P75, and P95 values for each class. Select a table row to display that class's 64-bin histogram below the table.

CSV export

Export CSV... writes the product name, ROI, validity rule, pixel counts, class and source-band provenance, summary statistics, percentiles, and histogram-bin counts. The CSV records analysis data; it does not export the displayed RGB image.
